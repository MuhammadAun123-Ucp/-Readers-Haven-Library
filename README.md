# Readers' Haven Public Library

A responsive static website for Readers' Haven Public Library.

## Technologies
- HTML5
- CSS3
- Node.js
- Parcel
- Docker
- Nginx

## Pages
1. Home
2. Collections
3. Membership
4. Digital Services
5. Contact & Feedback

## Project Build
npm ci
npm run build

## Docker
The website is containerized using a multi-stage Dockerfile.
